# Administrative boundary data

`bgd_admin3_ocha_simplified.geojson` contains simplified Bangladesh ADM3 (upazila) boundaries used by the Interactive Map search and outline layer.

- Boundary year represented: 2020
- Original source: Bangladesh Bureau of Statistics (BBS), published through OCHA ROAP
- Dataset metadata: [geoBoundaries Bangladesh ADM3](https://www.geoboundaries.org/api/current/gbOpen/BGD/ADM3/)
- License: CC BY 3.0 IGO; attribution is required
- Geometry is simplified for display. It is used for administrative search/visualization only, not for field surveying or environmental measurements.

The endpoint returns only upazila features spatially contained in the selected project's supported district (Cumilla or Chattogram). Environmental readings remain subject to the coverage and resolution stated by their source APIs.
